# 本次实现：跳空因子

[研究程序](../../projects/gap_research/research.py)、[输入与指令](../../projects/gap_research/README.md)、[冻结方案](../../reports/gap_round_01/protocol.md)。

16 候选从当日/累积跳空、意外跳空、波动缩放、方向一致性、量能确认到隔夜/日内分解。所有候选在 T 收盘后形成，按独立交易日历预测 T+1 至 T+3 收盘收益；滚动基准不使用未来数据。

真实研究先用 `--freeze-only` 登记协议、数据、实现和环境，再单次评估全部候选的训练/验证结果。训练选最高正向平均日 IC；验证通过后才允许单次显式 `--open-test`，历史测试只描述选中候选。保存全候选开发期结果、日 IC、输入哈希、数据审计和冻结协议，失败也留痕。统计是截面相关，不是收益率；g16 有日内反转成分。本地登记不能证明数据未被查看，也不支持同一冻结目录追加未来数据。
