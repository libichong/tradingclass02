# 本次实现：底层 CTP 演示

[程序](../../projects/ctp_demo/demo.py) 与 [运行说明](../../projects/ctp_demo/README.md)。

核心分离：原生 API 子类接柜台回调，`Session` 管理连接/认证/登录/订阅和请求编号，`Recorder` 输出可审计 JSONL。测试以替身验证状态流程，正式运行只在入口加载原生扩展，缺少扩展时报错，不偷偷切换假行情。

默认持续运行至 `Ctrl+C`；限时验证只用显式 `--duration`。断线后清理对应状态，重连重新认证/登录/订阅。无效报价明确记录，计数区分所有回调与有效行情。

没有发单、撤单和结算确认功能。`orders_sent=0` 是实现边界，不是靠日志猜测零交易。现场成功尚待账号与原生环境，离线测试不能证明真实登录。

来源：[CTP 源码摘要](../sources/vnpy-ctp.md)。下一步仅 [下单审核方案](order-plan.md)。
