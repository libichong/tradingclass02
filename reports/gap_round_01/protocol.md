# 第一轮事前方案（真实数据尚未运行）

制定日期：2026-10-11。对应原题每轮 10–20 个、最多四轮。本次固定 16 个，不运行扩展模型。外部报告的实验数字不视为本次结果。

## 冻结规则

- 输入：一致复权的股票日线 OHLCV、独立交易日历。课程缓存尚未提供。
- 信号：T 收盘后形成；不声称开盘即能得到当天成交量或日内收益。
- 标签：`close[T+3] / close[T+1] - 1`。按全市场交易日历移位；要求 T、T+1、T+2、T+3 的收盘值存在。
- 分段：2008–2016 训练，2017–2018 验证，2019–2020-08 历史测试。分段末尾标签越界的 T 排除；测试开始之前的价格可用于滚动特征预热。
- 选择：只在训练有效日 >=60 且平均 IC >0 的候选中选最高者，并列按因子名称。不反向因子符号、不看测试择优。
- 验证：有效日 >=20、平均 IC >0.01 且 HAC 95% 区间下界 >0。历史测试有效日 >=20，仅描述，不回改。
- 每天至少 30 个配对有效标的；并列平均秩；常数截面无 IC。
- Newey–West/Bartlett 权重，滞后 5 个交易日，渐近 95% 区间。不等于多重检验后的显著性。

机器规则在 [protocol.json](protocol.json)，完整实现与列契约在 [研究说明](../../projects/gap_research/README.md)。

## 16 个候选

记 `G=log(open/previous_close)`，`I=log(close/open)`，`R=log(close/previous_close)`；`RV=volume/过去20日量均值`。基准均值、标准差、波动和量均值都只用 T-1 及之前数据；滚动候选可包括 T 收盘已知数据。

| 编号 | 表达式 | 意图 |
|---|---|---|
| g01 | G | 当日隔夜跳空 |
| g02 | mean(G,3) | 短窗跳空 |
| g03 | mean(G,5) | 周窗跳空 |
| g04 | mean(G,10) | 两周跳空 |
| g05 | mean(G,20) | 月窗跳空 |
| g06 | G - past_mean(G,20) | 意外跳空 |
| g07 | (G - past_mean(G,20))/past_std(G,20) | 跳空标准化 |
| g08 | G/past_std(R,20) | 波动缩放 |
| g09 | mean(G,5)/past_std(R,20) | 累积波动缩放 |
| g10 | mean(sign(G),5) | 方向一致性 |
| g11 | mean(G>0,10) | 正向占比 |
| g12 | G*log(1+RV) | 当日量能确认 |
| g13 | mean(G*log(1+RV),5) | 多日量能确认 |
| g14 | G*sign(I) | 日内方向交互，非纯延续 |
| g15 | mean(G+I,5) | 隔夜与日内共同动量 |
| g16 | mean(G-I,5) | 隔夜减日内，含反转 |

窗口中缺失日不补值；分母为零记缺失。保存所有候选，包括负向、无效和未选中结果。
